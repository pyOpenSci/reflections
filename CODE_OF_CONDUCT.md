# Code of Conduct

As a pyOpenSci-sponsored project, reflections follows the
[pyOpenSci Community Code of Conduct][pyopensci-coc]. It applies to all project
spaces and interactions, including issues, pull requests, reviews, and other
project discussions.

The code describes expected behavior, enforcement, and how to report a
violation. Reports may be sent confidentially to the pyOpenSci Code of Conduct
stewards at `coc@pyopensci.org`.

[pyopensci-coc]: https://www.pyopensci.org/handbook/CODE_OF_CONDUCT.html
